# Logic circuit simulator

Create switches, gates, and lights; wire a circuit and test its output in original BASIC.

Internal/URL name: `logic`. The unlinked second gallery (`#/more`) offers only
one playable reference: **v05**, tape15b save 18.
The web experience starts at **v1** and stays there until the user says otherwise.
Other recovered saves are downloadable source, not additional player editions.

## Recovered history

Inferred from five consecutive tape15b saves. Later forms add device identification, initialization, reset, and truth-table functionality; source grows from 45 to 116 lines. Dates are not established. The latest complete save is the selected reference.

5 complete saves are preserved in `versions/`, including repeats.
Their raw payloads and readable listings were copied byte for byte from the
recovery archive. Source spelling, bugs, pointers, and line numbers are unchanged.
Canonical `LOGIC.ASC`, `LOGIC.BAS`, and provenance paths in
`original/` advance through individual `logic-vNN` Git commits/tags; permanent
snapshots remain alongside them. `provenance.json` records hashes, original
archive paths, inventory evidence, and dating limits.

Instructions live in the player's Help and About/source section. See
`VERIFICATION.md` for commands, executed checks, and remaining limits.
