# Nuclear Equation Completer

1 complete captured save(s) preserved. The player selects v01
(tape14a save 8). Other recovered forms are source only.

## Play

Try `U238=TH234+` at TYPE PROBLEM. `2:HE:4` is the result’s atomic-number:element:mass format for helium-4. Enter `H!` for the original syntax help. After a result, press Enter to continue. Restart resets all variables.

Click the screen for keyboard focus, or use the answer field. Help pauses and
restores the previous pause state. Pause/Resume stops and starts the machine;
Restart begins a fresh session. Keys are released on blur, navigation, pause,
and restart. Links open the player directly, with no launch page.

## History and limits

The complete tape14a save is playable. A damaged tape22a save remains source only in partial/, with 1294 verified prefix bytes, 32 ordered lines through 4010, and independent left/right agreement. No synthetic end marker or repaired bytes were added. Its historical table and parsing behavior are preserved; no general correctness claim is made.

One complete captured source; a separately preserved damaged tape22a recording is not promoted to a complete version. Their relative chronology is unknown.

Historical bytes and spellings are unchanged in versions/ and original/.
Tags nuclear-vNN identify canonical revisions, committed in the documented
inferred order. provenance.json records archive paths, hashes, and record
validation; VERIFICATION.md separates that evidence from new runtime checks.
The browser experience stays at unshared web v1.

From app/, run `npm run dev`, then open `/?development=1#/program/nuclear`.
