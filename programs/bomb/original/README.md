# Bomb — source through time

`BOMB.ASC` and `BOMB.BAS` are unchanged copies of one recovered version.
`provenance.json` identifies that version and its original archive files.

These same paths evolve through two consecutive Git commits in the inferred
development order. Tags `bomb-v01` and `bomb-v02` identify those commits. v01 is
the whole menu save (Bomb, radio intersection and binary search); v02 is Bomb on
its own, rewritten with new line numbers, so the diff between them is large.

Both versions remain available together under `../versions/`; the website uses
those snapshots. No source has been corrected or rewritten to create this history.
