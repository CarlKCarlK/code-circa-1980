# TUTAC Computer

Run a decimal computer simulator and its embedded punched-card program.

The site runs the untouched v01 payload through the original TRS-80 ROM. Other captured forms remain source only.

Consecutive complete saves add subtraction and experimental multiplication. v01 runs its embedded addition deck; v02 contains debugging STOP statements. A separate suspect v03 candidate remains in review/.
