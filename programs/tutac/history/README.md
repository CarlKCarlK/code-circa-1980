# Source history and dating

Consecutive complete saves add subtraction and experimental multiplication. v01 runs its embedded addition deck; v02 contains debugging STOP statements. A separate suspect v03 candidate remains in review/.

The source explicitly says COMPUTER LIKE IN TUTOR TEXT. Theodore G. Scott’s Basic Computer Programming describes the TUTAC teaching machine. Its decimal card layout and opcodes 00/15/25/50/60/61/62 match the recovered interpreter. The independent modern Python simulator confirms the design reference but is not a historical BASIC ancestor and is not inserted into canonical history.
