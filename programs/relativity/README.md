# Relativity

1 complete captured save(s) preserved. The player selects v01
(tape22a save 10). Other recovered forms are source only.

## Play

Press Enter at the title, then choose `1`, `2`, or `3`. For option 1 try rod length `40` and speed `80` percent of light speed. Option 2 draws a graph; optional Fast (20×) makes it practical to explore. Original (1×) remains the default. For option 3 try `80`. Any key returns from the rod/graph; Restart returns to the title.

Click the screen for keyboard focus, or use the answer field. Help pauses and
restores the previous pause state. Pause/Resume stops and starts the machine;
Restart begins a fresh session. Keys are released on blur, navigation, pause,
and restart. Links open the player directly, with no launch page.
