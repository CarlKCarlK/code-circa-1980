# Castles — source through time

`CASTLES.ASC` and `CASTLES.BAS` are unchanged copies of one recovered version.
`provenance.json` identifies that version and its original archive files.

These same paths evolve through five consecutive Git commits in the inferred
development order. Tags `castles-v01` through `castles-v05` identify those commits.
Use GitHub's file history or compare the tags to see the source changes.

The main branch ends at the latest inferred historical version (v05), which needs
external machine code. The website now supplies its separately derived FALL v6
routine; self-contained v03 remains available for comparison. All five
versions remain available together under `../versions/`; the website uses those
snapshots. No source has been corrected or rewritten to create this history.
