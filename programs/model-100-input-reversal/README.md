# Model 100 Input Reversal

Original author and any earlier published source have not been established. Preserved here as recovered cassette material.

Within each capture, save order is retained. Cross-capture ordering is a presentation guess; tape numbers do not establish development dates. Similarity clusters are provisional, and collected saves are not necessarily revisions of one program.

Reference: v08. Source only: Incomplete, uncertain, or nonstandard captured payload; see the recovery validation. This format or machine is not supported by the shared stock Level II BASIC player.

Permanent snapshots are in versions/; canonical files advance per save in Git with program-specific tags. All files and capture identities are in provenance.json.

## Model 100 player (November 3, 2026)

The website now runs v08 (tape2a2 save 19) in VirtualT’s emulated Model 100. The original accepts .X and Enter and prints reversed bits 1 0 and numeric value 2. Pause, Help, focus isolation, key release, and restart were checked.

Recovered files and canonical history are unchanged. Cassette framing removal, an in-memory terminal pointer, and relocation are loading adaptations only. See [Model 100 execution notes](../../docs/model100-player.md) for dependencies, tests, and limits.
