# Go

From a 1982 MMSFORTH disk; the source names no author. Runs on MMSFORTH V2.0, © 1981 Miller Microcomputer Services. Preserved here for small-scale archival use.

Two-player Go on a 19-by-19 board drawn in TRS-80 graphics.

Permanent snapshots are in versions/; canonical files advance per save in Git with program-specific tags. Disk images and hashes are in provenance.json. The recovered bytes are unchanged.
