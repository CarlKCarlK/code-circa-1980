# Published-source comparison baseline

Roger Chaffee, Quest, BYTE July 1979, pp. 176–186. Selected dispatcher/room records from Listing 2 only. This is an intentionally incomplete comparison excerpt, not a complete ancestor or executable. ASCII punctuation and keyword spacing transcribed from the published listing; spacing is not archival byte evidence. Other Quest records are omitted, not reconstructed from Jaberwocky. The available IF Archive GW-BASIC port was not used as an exact original: its numbering, text, and trailer differ.

Source: https://www.worldradiohistory.com/Archive-Byte/70s/Byte-1979-07.pdf

This baseline precedes the recovered snapshots in canonical Git history. It is source only and has no synthetic recovered cassette payload.
