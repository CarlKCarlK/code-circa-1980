# Jaberwocky: source and dating

The tape20a save 3 is the only identified complete captured form. Roger Chaffee’s Quest, BYTE July 1979, pp. 176–186, supplies the numbered dispatcher at 8200–8290 and many descriptions in the 9000s. The first canonical comparison commit is explicitly a selected, non-executable Quest excerpt; it is not the whole original game. The complete electronic Quest port found at IF Archive changes room numbering/text and contains a trailing fragment, so it was not represented as the exact published original.

Jaberwocky replaces Quest’s fixed treasure-hunt graph with randomly connected caverns, a moving monster, three crossbow stingers, and seven dynamite charges. Shared room numbers/text establish borrowing, not who performed the adaptation. Publication in July 1979 suggests mid-1979 or later if BYTE was the source; Quest circulated earlier, so this is conditional. No date appears in the recovered game.

Neighbor context: tape20a’s Football, Monopoly draft, and Speech Coaching saves contain no useful contemporary source date. Opposite-side SPI has a 1974 copyright notice and AIM a 1977 notice; neither dates these adaptations. Relative creation/save order with Alien and Cave Game is unresolved. Their shared sealing mechanic is evidence of a design connection, not a proven ancestry.
