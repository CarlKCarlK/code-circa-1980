# Computa-Match

## Play

The sample calculation and formatted reports start automatically. Pause to read a report, Resume to continue, and Restart to rerun it.

The original BASIC runs through the shared Z80/ROM emulator. Click the screen
for keyboard focus. Help pauses/restores the prior state; Pause freezes execution;
Restart begins fresh. Keys are released on blur, navigation, pause, and restart.

## Source and history

Four consecutive file8b saves retain early validation drafts and increasingly complete matching reports. The default is save 16 (v04), credited to Carl Kadie for Woodruff’s student council, January 6, 1980. Its sample data mixes names, seven-digit phone-like fields, and clearly fictional entries; their real-world accuracy is not established. The dataset is preserved unchanged. The quarantined file8b sentence program is excluded.

Four consecutive saves progress from data validation to matching and formatted result reports. Earlier drafts and the repeated early form remain separate. The latest source credit says January 6, 1980; this is not a tape-save date.

Recovered payloads/listings are unchanged in versions/ and original/. Tags
computamatch-vNN identify canonical per-save revisions. provenance.json records paths,
hashes, structure, and recovery evidence separately from new emulator testing.
See VERIFICATION.md for execution checks and limits. The experience stays at
unshared web v1. From app/ run `npm run dev` and open
`/?development=1#/program/computamatch` directly.
