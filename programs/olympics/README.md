# Olympics

Coach a nation’s team through invented Olympic events, training, and medal ceremonies.

Shown only in the unlinked second gallery (`#/more`). The player runs v03 unchanged through the TRS-80 emulator.

Inferred: tape3apartial save 1 and tape3a save 1 are identical repeated captures of the earlier form; tape3a save 2 adds the 1980 copyright, revised event names and further checks. Capture order alone does not date the program.

All recovered snapshots are retained in `versions/`. `original/` advances through
individual commits and program tags; its latest historical snapshot may differ
from the playable default. Hashes, archive links, and inventory evidence are in
`provenance.json`. Recovery validation did not include execution testing. See
`VERIFICATION.md` for new website checks.
