# 3-D Plot — source through time

`PLOT3D.ASC` and `PLOT3D.BAS` are unchanged copies of one recovered version.
`provenance.json` identifies that version and its original archive files.

These same paths evolve through three consecutive Git commits in the inferred
development order. Tags `plot3d-v01`, `plot3d-v02` and `plot3d-v03` identify
those commits.

All versions remain available together under `../versions/`; the website uses
those snapshots. No source has been corrected or rewritten to create this history.
