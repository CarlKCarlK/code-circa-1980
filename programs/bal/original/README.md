# Chemical Equation Balancer — source through time

`BALANCER.ASC` and `BALANCER.BAS` are unchanged copies of one recovered version.
`provenance.json` identifies that version and its original archive files.

These same paths evolve through twenty consecutive Git commits in the inferred
development order. Tags `balancer-v01` through `balancer-v20` identify those
commits. v01–v08 are the 1979 Chemical Equation Balancer; v09 starts the 1981
Chemistry Balancer II rewrite, so the v08→v09 diff replaces the whole file.

All twenty versions remain available together under `../versions/`; the website
uses those snapshots. No source has been corrected or rewritten to create this
history.
