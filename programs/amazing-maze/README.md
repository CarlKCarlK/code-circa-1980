# Amazing Maze

Adapted from Jack Hauber’s Amazing, published in BASIC Computer Games (Creative Computing). The exact intermediate edition is unverified.

Within each capture, save order is retained. Cross-capture ordering is a presentation guess; tape numbers do not establish development dates. Similarity clusters are provisional, and collected saves are not necessarily revisions of one program.

Reference: v05. The player loads one complete recovered stock-BASIC payload. Historical bugs remain. No BASIC gameplay testing was performed in this import.

Permanent snapshots are in versions/; canonical files advance per save in Git with program-specific tags. All files and capture identities are in provenance.json.

The player boots the original Games Diskette and picks this program from its menu; the disk form is the selected version. Earlier cassette saves remain source only.
