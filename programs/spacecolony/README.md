# Space Colony

## Play

Answer NO, then press Enter at the continuation prompt. For a first-year budget, try 0 area sold, 50000 distributed to workers, 500 collector area re-energized, and 0 for pollution control. Follow continuation keys and yearly reports. Restart starts fresh.

The original BASIC runs through the shared Z80/ROM emulator. Click the screen
for keyboard focus. Help pauses/restores the prior state; Pause freezes execution;
Restart begins fresh. Keys are released on blur, navigation, pause, and restart.
