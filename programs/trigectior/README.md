# Trajectory

2 complete captured save(s) preserved. The player selects v02
(tape22a save 4). Other recovered forms are source only.

## Play

Enter speed `20`, angle `45`, and screen height `40`. At `<DONE>`, press a key for flight statistics. Restart begins a new plot.

Click the screen for keyboard focus, or use the answer field. Help pauses and
restores the previous pause state. Pause/Resume stops and starts the machine;
Restart begins a fresh session. Keys are released on blur, navigation, pause,
and restart. Links open the player directly, with no launch page.
