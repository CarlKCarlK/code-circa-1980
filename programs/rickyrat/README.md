# Ricky Rat

Two rats race through a generated maze, using the original 1982 BASIC algorithms.

Internal/URL name: `rickyrat`. The unlinked second gallery (`#/more`) offers only
one playable reference: **v15**, tape18b save 18.
The web experience starts at **v1** and stays there until the user says otherwise.
Other recovered saves are downloadable source, not additional player editions.

## Recovered history

Inferred from source changes and within-side save order. All complete saves are on tape18b; saves 2 and 3 repeat the first form. Saves 15 and 19 are damaged and remain separate. Import v15 is recovery-label V14, save 18, the latest complete form. The later damaged V15 is not substituted or repaired.

15 complete saves are preserved in `versions/`, including repeats.
Their raw payloads and readable listings were copied byte for byte from the
recovery archive. Source spelling, bugs, pointers, and line numbers are unchanged.
Canonical `RICKYRAT.ASC`, `RICKYRAT.BAS`, and provenance paths in
`original/` advance through individual `rickyrat-vNN` Git commits/tags; permanent
snapshots remain alongside them. `provenance.json` records hashes, original
archive paths, inventory evidence, and dating limits.

Instructions live in the player's Help and About/source section. See
`VERIFICATION.md` for commands, executed checks, and remaining limits.
