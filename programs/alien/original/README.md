# Alien — source through time

`ALIEN.ASC` and `ALIEN.BAS` are unchanged copies of one recovered version.
`provenance.json` identifies that version and its original archive files.

These same paths evolve through two consecutive Git commits in the inferred
development order. Tags `alien-v01` and `alien-v02` identify those commits.

Both versions remain available together under `../versions/`; the website uses
those snapshots. No source has been corrected or rewritten to create this history.
