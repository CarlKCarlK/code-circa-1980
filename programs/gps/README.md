# GPS Planner

I wrote this in LISP. It runs on LISP 3.72, © 1981 Ronald L. Nicol, distributed by SuperSoft. Preserved here for small-scale archival use.

A General Problem Solver in LISP: it plans how to push a box, climb, and grasp by working on the largest difference between the current state and the goal.

Permanent snapshots are in versions/; canonical files advance per save in Git with program-specific tags. Disk images and hashes are in provenance.json. The recovered bytes are unchanged.
