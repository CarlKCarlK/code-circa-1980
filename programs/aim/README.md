# Automatic Investment Management

## Play

The last data-bearing save, tape20b save 12 (v04), runs automatically at a 20× target. Choose original 1× to watch its table. Pause to read; Restart repeats the same data. The Investing program selector switches to SPI.

The original BASIC runs through the shared Z80/ROM emulator. Click the screen
for keyboard focus. Help pauses/restores the prior state; Pause freezes execution;
Restart begins fresh. Keys are released on blur, navigation, pause, and restart.

## Source and history

Four complete captures and two damaged fragments remain separate from SPI. Both source headers credit Robert Lichello’s book and Carl Kadie’s programming. The 1977 notice does not establish the program’s creation or save date. AIM is grouped under SPI’s gallery card, not labeled as an SPI revision.

Within-side save order, with expanded sample data and a separate empty-data template. AIM remains distinct from SPI; they are related programs, not successive versions of one algorithm.

Recovered payloads/listings are unchanged in versions/ and original/. Tags
aim-vNN identify canonical per-save revisions. provenance.json records paths,
hashes, structure, and recovery evidence separately from new emulator testing.
See VERIFICATION.md for execution checks and limits. The experience stays at
unshared web v1. From app/ run `npm run dev` and open
`/?development=1#/program/aim` directly.
