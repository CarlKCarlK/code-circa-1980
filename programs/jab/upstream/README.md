# Published-source comparison baseline

Jack Hauber, Amazing, BASIC Computer Games (1978), pp. 2–3. Complete electronic transcription obtained from the GReaperEx/bcg mirror of Vintage BASIC. Not a recovered cassette or verified byte-for-byte transcription of the print edition. Published source attribution and the maze-generation algorithm match the early tape16a forms; numbered records are reorganized there. The later JAB forms replace the generator. No claim that the complete JAB game came from this book.

Source: https://raw.githubusercontent.com/GReaperEx/bcg/master/amazing.bas

This baseline precedes the recovered snapshots in canonical Git history. It is source only and has no synthetic recovered cassette payload.
