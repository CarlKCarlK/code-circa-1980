# Dungeon Trainer

Practice fantasy combat with armor, weapons, parrying, and withdrawal.

The site runs the untouched v02 payload through the original TRS-80 ROM. Other captured forms remain source only.

Text prototypes precede the graphics-extension branch by source features; cross-tape chronology is inferred. The self-contained text v02 is playable; later LINE/GET/PUT animation forms require an unavailable graphics extension.
