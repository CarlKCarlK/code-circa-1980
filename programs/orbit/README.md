# Orbit simulator

Plot a spacecraft’s motion around massive bodies with an early BASIC gravity simulation.

Internal/URL name: `orbit`. The unlinked second gallery (`#/more`) offers only
one playable reference: **v06**, tape11b save 17.
The web experience starts at **v1** and stays there until the user says otherwise.
Other recovered saves are downloadable source, not additional player editions.

## Recovered history

Inferred from source changes and tape11b save order: six labeled forms, with later forms adding adaptive scale and setup options. The v1–v4 and v5–v6 groups are parts of the same simulator. Some latest menu branches are unfinished historical code; completeness of cassette recovery is separate from runtime behavior.

6 complete saves are preserved in `versions/`, including repeats.
Their raw payloads and readable listings were copied byte for byte from the
recovery archive. Source spelling, bugs, pointers, and line numbers are unchanged.
Canonical `ORBIT.ASC`, `ORBIT.BAS`, and provenance paths in
`original/` advance through individual `orbit-vNN` Git commits/tags; permanent
snapshots remain alongside them. `provenance.json` records hashes, original
archive paths, inventory evidence, and dating limits.

Instructions live in the player's Help and About/source section. See
`VERIFICATION.md` for commands, executed checks, and remaining limits.
