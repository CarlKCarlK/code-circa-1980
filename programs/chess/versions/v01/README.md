# CISAB Chess — v01: COMPUTER CHESS · Plays itself

Archive: tape1b, save 8 (archive label COMPUTER CHESS).
Also tape1b2 save 8: identical (second capture of the same side).

The earliest recovered version: moves for every piece (bishops, rooks and queens step along angles with COS and SIN), and the computer takes the most valuable piece it can. Line 80 jumps past the human move to line 81, which turns the board around, so it plays both sides.

Order 1 of 14 is an inferred development order. The ASC and BAS files are
unchanged recovered artifacts. See ../../provenance.json for hashes and evidence.
