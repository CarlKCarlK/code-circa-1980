# CISAB Chess — source through time

`CHESS.ASC` and `CHESS.BAS` are unchanged copies of one recovered version.
`provenance.json` identifies that version and its original archive files.

These same paths evolve through fourteen consecutive Git commits in the inferred
development order. Tags `chess-v01` to `chess-v14` identify those commits, so
`git diff chess-v05 chess-v06 -- programs/chess/original/CHESS.ASC` shows one
step of the program's growth.

All versions remain available together under `../versions/`; the website uses
those snapshots. No source has been corrected or rewritten to create this history.
